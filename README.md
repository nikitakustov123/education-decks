# Presentation Portfolio

Designed and built by **nikitakustov123**.

40 presentations: 30 interactive HTML decks that play in the browser and 10 native PowerPoint files. Every deck has its own visual style, typefaces and custom animated transitions.

> **Concept work.** Every company, product, person and figure in these decks is fictional and used as placeholder content, not real client work. Each deck carries a small *Concept work · fictional company* badge in a corner.

**Live gallery:** https://nikitakustov123.github.io/education-decks/

**Russian version (Русская версия):** https://nikitakustov123.github.io/education-decks/ru/ — all 30 HTML decks and 10 PowerPoint files translated, with Cyrillic-ready fonts.

## Viewing

- **In the browser:** open the live gallery and pick a deck. Navigate with the ← → keys, a click or a swipe.
- **PowerPoint:** download a `.pptx` from the gallery or open it in the browser with Office Online. Morph transitions and motion paths work best in PowerPoint 2019, 2021 or Microsoft 365.
- **Locally:** run `python3 -m http.server` in the repository root and open `http://localhost:8000`. Each HTML deck is a single self-contained file with no build step.
